# Contributing to mspu

Thank you for considering a contribution to this project! To keep reviews fast and the git history clean, please follow these guidelines.

## Code Style & Formatting Guidelines

- **Keep PRs Atomic:** Each Pull Request should address **one specific bug fix or feature**. Do not bundle in reformatting, unrelated doc updates, or unrelated tests.
- **No Pure Reformatting:** Do not submit PRs that solely restructure or reformat code, and avoid touching lines unrelated to your fix — this keeps diffs and git history clean. We deliberately keep formatting requirements relaxed to minimize diff clutter.

## Submitting a Pull Request

1. Focus strictly on the logic fix or feature implementation.
2. Include or update unit tests specific to your changes.
3. Keep PR descriptions brief and focused on the *why* and *what* of the change.
